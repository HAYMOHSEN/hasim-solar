## Hasim Solar 1.3.0

Windows installer for Hasim Solar – solar PV design & quotation software for installers.

**What's new in 1.3**
- Direct-sales edition: licence keys delivered automatically after purchase, in-app update check and buy links.
- World edition (1.2): 199 countries, 691 cities, 147 currencies, local price presets.
- 3D installation view and AutoCAD (DXF) import/export (1.1).

**Install:** download `HasimSolar-Setup-1.3.0.exe`, run it (SmartScreen may ask "More info → Run anyway" because the installer is not yet code-signed), then activate with your licence key or start the 14-day trial.
